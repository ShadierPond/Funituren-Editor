Legende / Anleitung – Furnituren Editor

  • 🖨️ Drucken: Öffnet ein Menü: „Aktuelle Kategorie drucken" oder „Alle Kategorien drucken".
  • Kategorie auswählen: Über das Dropdown wählst du die aktuelle Kategorie.
  • ➕ Neue Kategorie: Erstellt eine neue Kategorie mit 15 Feldern.
  • ✏️ Kategorie bearbeiten: Menü mit „Umbenennen" und „Löschen" der aktuellen Kategorie.
  • 💾 JSON speichern: Exportiert alle Daten (inkl. Reihenfolge und Fotos) als JSON-Datei.
  • 📂 JSON laden: Importiert eine gespeicherte JSON-Datei.
  • 🔍 Zoom: Vergrößert/verkleinert die Vorschau.
  • ✎ in jeder Zelle: Öffnet den Editor für Beschreibung, Beco, Referenz und festen Preis.
  • Foto: In der Zelle auf den Foto-Bereich klicken, um ein Bild hochzuladen.
  • Felder tauschen: Zellen per Drag & Drop ziehen und auf andere Zelle fallen lassen.
  • QR: Wird automatisch aus dem Referenz-Feld erzeugt.
  • Wichtig: Änderungen sind im Browser aktiv; für Sicherung immer JSON speichern.
